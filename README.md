# Argine Tolentino portfolio

A responsive, accessible static portfolio for ecommerce customer support and virtual assistance.

## View and publish

Open `index.html` in a browser for a local preview. GitHub Pages serves the site from the `main` branch at the repository root. No PHP server, installation, or build step is required.

## Maintain

- `index.html`: page content, work samples, contact details, and resume link.
- `styles.css`: layout, colors, responsive behavior, and print styles.
- `script.js`: keyboard-accessible work-sample tabs, mobile menu, copy-email button, and current year.
- `argine-portrait.webp`: the supplied portrait.
- `Argine-Tolentino-Resume.pdf`: the existing downloadable resume.

The sample customer conversations, appointments, and lead records are fictional and marked as illustrative on the page.

The page contains its own header, footer, and content. The previous PHP helper and data files are no longer used. JavaScript enhances navigation and work samples; the content remains readable without JavaScript.
